The pain

Friday night. Phone rings. Nobody picks up. That homeowner does not leave a polite voicemail. They call the next guy on Google.

What you want instead: the office wakes up to a usable lead. Who called, where they are, what broke, how urgent it is, when they want someone there.

That outcome is the product. Retell and n8n are how I get there.

How I build

  1. Problem — name the owner pain in plain language.
  2. Contract — fields, enums, when the tool may fire.
  3. Tool call — Retell custom function → n8n webhook.
  4. Validation — types and required keys before any CRM write.
  5. Failure path — timeout, missing data, and safety all fail closed to a human.
